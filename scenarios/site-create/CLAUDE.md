## Сценарий «Создать сайт»

Человек без технического опыта делает сайт вместе с тобой. Ведущий — помощник `site-lead`; он решает, какой навык подключить на каждом шаге.

Порядок работы:

1. `site-brief` — бриф: кто, для кого, что должен сделать посетитель.
2. `site-design` — направление дизайна: структура, палитра, шрифты, тон текстов.
3. `site-build` — вёрстка и тексты, сайт в папке `site/`.
4. `site-seo` — заголовки, описания, быстрый вид в поиске.
5. `legal-flags-ru` — юридические флажки (пробная версия), файл `юридические-флажки.md`.

Результат живёт в папке проекта. Сайт собирается как обычные файлы, которые открываются в браузере двойным щелчком, если человек не просил другого. Публикацию в интернет этот сценарий не делает: для неё есть сценарий «Запустить сайт».
