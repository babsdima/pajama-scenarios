# Выбор хостинга

Ты **не покупаешь** хостинг. Ты помогаешь выбрать и ведёшь человека по шагам, платит он.

## Шаг 1. Что нужно сайту

Спроси (по одному): сайт из готовых файлов или с базой данных и формами? Сколько посетителей ожидается? Нужна ли почта на домене? Нужен ли сервер в России (сбор данных людей из РФ, продажи)? Какой бюджет комфортен?

## Шаг 2. Критерии

- **Тип.** Для сайта из готовых файлов хватит простого хостинга для сайтов или площадки для статических сайтов. VPS (свой сервер) нужен, только если без него нельзя: он сложнее и требует обслуживания.
- **Где данные.** Если сайт собирает персональные данные людей из РФ, по открытым источникам данные должны храниться на территории РФ, а хостинг-провайдер должен быть в реестре Роскомнадзора. Скажи это как подсказку и порекомендуй проверить у юриста и в реестре. Если данных нет (простая визитка без форм и аналитики), требования мягче.
- **Цена целиком.** Сравнивай цену первого периода и цену продления, стоимость домена, почты, SSL (замочек), резервных копий.
- **Поддержка** на русском, понятная панель, резервные копии, бесплатный SSL.
- **Оплата.** Какими способами можно оплатить из вашей страны и в вашей валюте. Не предполагай, что любая карта подойдёт.
- **Выход.** Можно ли забрать сайт и уйти без потери данных.

## Шаг 3. Варианты

Подбери 2–3 варианта и **проверь каждый на официальной странице прямо сейчас** (открой страницу тарифов, поиск в интернете). Примеры категорий для проверки, не рекомендации: российские хостинги для сайтов (например, Timeweb, Beget, Reg.ru, Selectel) и площадки для простых статических сайтов (например, GitHub Pages, Cloudflare Pages, Vercel). Площадки за рубежом подходят только для сайтов без сбора персональных данных и без требования хранить данные в РФ; скажи об этом прямо. Не переписывай цены из памяти: бери с официальной страницы, указывай дату.

Результат шага — короткая таблица: вариант, для чего подходит, ориентировочная цена (с датой и ссылкой), плюсы, минусы, твоя рекомендация и почему.

## Шаг 4. Блок «Здесь платите вы»

Когда человек выбрал, выведи блок «Здесь платите вы» (по правилам проекта) и пошагово опиши регистрацию и оплату: что открыть, что выбрать (тариф, срок), что нажать, что проверить после. Подчеркни:

- Автопродление: включать или нет, решает человек; запиши дату продления в памятку.
- Двухфакторная защита аккаунта хостинга и надёжный пароль: человек делает сам, ты не просишь пароль в чат.

После блока остановись и жди «оплатил».

## Результат

Запись в `запуск-памятка.md`: выбранный хостинг, тариф, дата оплаты (со слов человека), дата продления, ссылка на панель. Без паролей.
