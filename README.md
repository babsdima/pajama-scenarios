# pajama-scenarios

Каталог «Готовых сценариев» для [Pajama](https://pajamacode.com): пакеты «агент-ведущий + навыки + правила проекта» под типовые задачи (создать сайт, запустить сайт, презентация и другие). Приложение скачивает отсюда сценарии и ставит их в папку проекта человека.

Репозиторий публичный, чтобы Pajama могла скачивать отсюда обновления сценариев (публичный адрес `raw.githubusercontent.com` отдаёт только открытые репозитории). Лицензия пока не выбрана: по умолчанию все права сохраняются за автором, использовать сценарии вне Pajama без разрешения нельзя. Юридические навыки пробные и ждут вычитки юристом: пользуйтесь ими с плашкой «проверьте у настоящего юриста».

## Что внутри

```
catalog.json                    индекс (собирается скриптом, руками не править)
shared/                         общие правила: style.md, money-and-publish.md, legal-disclaimer.md
shared/skills/<имя>/SKILL.md    навыки, общие для нескольких сценариев
scenarios/<id>/
  scenario.json                 паспорт сценария (карточка, «что понадобится», стартовая фраза)
  CLAUDE.md                     правила именно этого сценария
  agents/<ведущий>.md           агент-ведущий (и другие помощники)
  skills/<имя>/SKILL.md         навыки сценария
scripts/build-catalog.mjs       проверка и сборка catalog.json
test/                           тесты каталога
```

## Паспорт `scenario.json`

| Поле | Значение |
|---|---|
| `id`, `version`, `status` | имя папки; версия `1.2.3`; `trial` (пробная) или `stable` |
| `icon`, `legal`, `checked` | значок; юридический ли сценарий; дата последней проверки правил `ГГГГ-ММ-ДД` (обязательна, если `legal`) |
| `minApp` | с какой версии Pajama работает |
| `title`, `summary`, `result`, `time`, `startPrompt` | тексты на `ru` и `en` |
| `needs[]` | «что понадобится»: `kind` = `info`, `account`, `money`, `document` или `tool`, тексты `ru` и `en` |
| `lead` | имя файла ведущего в `agents/` |
| `shared[]` | общие правила; всегда `style` и `money-and-publish`, у юридических ещё `legal-disclaimer` |
| `skills[]` | навыки: `имя` — из `skills/` сценария, `shared:имя` — из `shared/skills/` |

## Обязательные правила для авторов

1. **Агент ничего не покупает и не публикует сам.** Правило лежит в `shared/money-and-publish.md` и подключается ко всем сценариям; проверка не пропустит сценарий без него. Помощникам нельзя выдавать инструменты MCP (`tools: mcp__…`).
2. **Юридическое — только с плашкой и датой проверки.** Любой сценарий с юридическими выводами помечается `legal: true`, получает `checked` и подключает `legal-disclaimer`. Настоящий юрист проверяет результат перед публикацией.
3. **Без выдумок.** Цены, тарифы, адреса, реквизиты агент берёт с официальных страниц в момент работы и указывает дату.
4. **Без секретов и опасного.** Ни ключей, ни `curl … | sh`: проверка это ловит.

## Как выпустить изменение

1. Поправьте файлы сценария и **поднимите `version`** в `scenario.json` (человек с установленным сценарием увидит «Есть обновление»).
2. Для юридических — обновите `checked`.
3. `node scripts/build-catalog.mjs` — пересоберёт `catalog.json` и увеличит `revision`, если что-то изменилось.
4. `node --test` и `node scripts/build-catalog.mjs --check`.
5. Закоммитьте `catalog.json` вместе с изменениями и отправьте в `main`. CI делает те же проверки.

Приложение подтянет изменения, когда человек откроет раздел «Готовые сценарии» (не чаще раза в несколько часов) или нажмёт «Проверить обновления». Фоновых запросов нет.

## Как это читает Pajama (контракт)

- `catalog.json`: `format` (сейчас `1`; приложение игнорирует другое число и просит обновиться), `revision` (растёт при любом изменении), `scenarios[]` со всеми полями паспорта и списком `files[]`.
- Каждый файл: `path`, `sha256`, `size`, `role` (`manifest`, `rules`, `agent`, `skill`) и `dest` (куда ставить относительно папок помощников или навыков).
- Приложение берёт индекс и файлы по **конкретному коммиту**, сверяет `sha256`, прогоняет проверку навыков и только потом ставит. Роль `rules` склеивается в блок `CLAUDE.md` и `AGENTS.md` в порядке списка.
- В приложение вшита копия каталога на случай отсутствия сети; она обновляется командой `npm run scenarios:bundle` в репозитории Pajama.
